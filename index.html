🐾 소피니티 콘텐츠 가이드

@sofinity_official · 인스타그램 운영 가이드 · 기획: 별, 진웅 · 2026.06

매일 한 질문에 답하며 반려친구를 기록하는 앱 소피니티의 공식 인스타 계정입니다.
콘텐츠 필러 2개 → A UGC(보호자 답변) 재가공 / B 오리지널 인사이트.
브랜드 톤 = 하늘색 + 화이트, 따뜻한 미니멀.

1 콘텐츠 캘린더 (주간)

요일콘텐츠포맷
월A UGC·보호자 답변피드
화B 오리지널 인사이트피드
수A UGC + B 릴스피드 + 릴스
목A UGC·보호자 답변피드
금B 오리지널 인사이트피드
토A (선택)피드
일쉼 / 스토리만스토리

+ 스토리는 데일리 — 당일 질문·신규 게시물 리그램 (리텐션).
※ 현재 A(UGC) 준비 중 → 우선 B(인사이트) 주 2~3회로 운영 시작.

2 콘텐츠 샘플

B 산책은 운동이 아니라 '편지 읽기'

오리지널 인사이트
  • 후크 — "산책이 운동이라고 생각하셨나요?"
  • 통념 — 산책 = 에너지 빼주기
  • 반전 — 냄새 맡기 = 세상의 소식을 읽는 일
  • 실천 — 천천히 냄새 맡게 기다려주기
  • CTA — 마무리 한 줄 + 팔로우 유도

비주얼: 코 박고 냄새 맡는 강아지 (실사) · 하늘색/화이트 톤

B 우리 아이가 나를 빤히 볼 때

오리지널 인사이트
  • 후크 — "빤히 쳐다볼 때, 무슨 생각일까요?"
  • 통념 — 그냥 배고프거나 심심해서
  • 반전 — 눈맞춤은 서로에 대한 애정 표현
  • 실천 — 오늘 한 번 마주봐 주기
  • CTA — 다음 편 예고 + 팔로우 유도

비주얼: 보호자를 올려다보는 강아지 눈 (실사) · 따뜻한 톤

A 오늘의 보호자님 (UGC — 동의·준비 중)

UGC 재가공
  • 오늘의 질문
  • 보호자 답변 ①
  • 보호자 답변 ②
  • CTA — "내일은 어떤 질문이?" + 인앱 유도

포맷 선확정 → UGC 준비되는 대로 카피만 교체해 주 3~4회 발행

B 콘텐츠 백로그: 분리불안 진실 / 강아지 나이 ×7은 틀렸다 / 여름 아스팔트 5초룰 / 카밍 시그널 / 이름 자주 부르면 안 되는 이유 / 간식 타이밍

3 크리에이티브 가이드라인

  • 비주얼: 실사 우선 — 그래픽 대비 도달·인게이지먼트 우위 (데이터 확인됨)
  • 컬러: 하늘색 + 화이트 + 여백 — 현 브랜드 톤 유지
  • 마지막 슬라이드 = CTA — "다음 편 팔로우" + "프로필 링크 → 소피니티 앱"
  • 카피 톤 — 보호자님 / 반려친구, 쉬운 구어체
  • 우하단 soft & warm things 시그니처 고정
